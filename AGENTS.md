# AGENTS.md

Инструкции для агента в репозитории SkyMunky / Aeroflot ОТО. Сначала определи текущую ветку (`git branch --show-current`) и соблюдай границу ниже. Явный запрос пользователя на конкретный файл важнее границы, но только для этого запроса.

## Граница ветки

Агент пишет код только в дереве своей ветки.

| Текущая ветка | Можно менять | Нельзя менять |
|---|---|---|
| `backend` или имя с префиксом `backend` | `backend/**` | `frontend/**` |
| `frontend` или имя с префиксом `frontend` | `frontend/**` | `backend/**` |

Если правка API требует изменений на другой стороне, не делай их. Напиши, какой файл и какой контракт нужно поменять, и остановись.

`docs/`, `tools/`, `docker-compose.yml`, `README.md` и этот файл не принадлежат ни одной стороне. Меняй их только когда пользователь прямо попросил.

На `master` не меняй `backend/` и `frontend/`, пока пользователь не назвал сторону.

## Что это за проект

Диспетчер назначает инженера на неисправность самолёта. Бэкенд строит маршрут по клеточной карте, хранит пользователей и задачи в PostgreSQL, позиции и AOG в Redis.

```text
backend/     Rust, Axum, Diesel, Redis. API под /api, OpenAPI на /swagger
frontend/    Статические HTML/JS: вход, карта диспетчера, экран инженера, демо
tools/       parser (карта .tmj) и scheduler (автозакрытие задач)
docs/        Техническое описание
```

Роли: `Dispatcher` и `Engineer`. Почта уникальна сразу в обеих таблицах.

## Бэкенд

Запуск из `backend/`: `cargo run -- --map-path ./assets/map2.json`. Проверка: `cargo check`. Миграции Diesel применяются при старте.

Новая ручка заводится в трёх местах сразу, пути должны совпадать буквально:

1. маршрут в `backend/src/main.rs`;
2. `path =` в `#[utoipa::path]`;
3. регистрация пути и схем в `backend/src/types/doc.rs`.

Префиксы: `/api/auth`, `/api/geo`, и защищённые `/api/map`, `/api/getRoute`, `/api/assign`, `/api/aircraft`, `/api/tasks/...`. Геопозиция инженеров, самолётов и спецтранспорта живёт в `backend/src/router/geo.rs`, не в `simulate`.

Позиция самолёта: Redis `position:aircraft:{uuid}`. `POST /api/assign` принимает `plane_uuid`, не координаты. AOG ставит инженер по самолёту своей активной задачи (`aog:{uuid}`). `POST /api/geo/updateEngineerPosition` принимает `id` и `batch` пар `[point, unix_timestamp]`; в Redis пишется точка с самым поздним временем.

Bruno-запросы: `backend/test/api/*.yml`. `{{HOST}}` уже включает `/api`.

## Фронтенд

Статика без сборки. Раздача из корня репозитория: `python -m http.server 8001`. Вход: `http://127.0.0.1:8001/frontend/index.html`.

Пути в `apiRequest` копируются с бэкенда как есть, включая регистр (`/api/geo/updateEngineerPosition`, не snake_case). Контракт полей не выдумывается: его источник — DTO и OpenAPI бэкенда.

## Общие ограничения

- Не коммить и не пушить, пока пользователь не попросил.
- Не менять git config и не делать force push.
- Секреты (`.env`, пароли, токены) не коммитить и не вставлять в новые файлы.
- Для бэкенда после изменения Rust запускать `cargo check` в `backend/`.
